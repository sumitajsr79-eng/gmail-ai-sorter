🔐 How to Generate a Gmail App Password

An App Password is a 16-digit passcode that grants this app secure access to your Gmail without needing Google Cloud API authorization!

  1. Go to your Google Account Security Settings.
  2. Make sure 2-Step Verification is turned ON.
  3. Search for "App passwords" in the search bar or visit myaccount.google.com/apppasswords.
  4. Enter an App name (e.g. AI Gmail Sorter) and click Create.
  5. Copy the generated 16-character password and paste it into Option 1 above!

🔐 Google OAuth Setup Instructions

  1. Go to the Google Cloud Console.
  2. Create a project and enable the Gmail API.
  3. Configure the OAuth Consent Screen.
  4. Create an OAuth 2.0 Client ID (Web Application).
  5. Set Authorized Redirect URI to http://localhost:5000/oauth2callback.
  6. Save downloaded file as credentials.json inside the application directory.
